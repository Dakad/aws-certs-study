# Repo-local skills

These skills describe how to maintain and teach from this study repository:

- [AWS CloudOps tutoring](aws-cloudops-tutoring/SKILL.md) — session flow, balanced exam coverage, learner-specific pacing, and evidence-based progress tracking.
- [AWS knowledge graph](aws-knowledge-graph/SKILL.md) — canonical notes, relationships, original scenarios, and graph maintenance.

Use the tutoring skill for lessons and the knowledge-graph skill when authoring or restructuring study content. They are complementary; the tutoring skill records learner evidence in the journal, while the graph skill maintains reusable technical knowledge.
