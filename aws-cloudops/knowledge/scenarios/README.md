# Scenarios and future quiz questions

Write original, operational scenarios that connect multiple graph nodes. Include the prompt, evidence, best answer, why plausible alternatives do not fit, uncertainty/assumptions, and a follow-up check. Link the tested nodes so future quiz results can point to the concept to review.

Do not import paid or copyrighted exam questions. Record your actual response, correction, and demonstrated skill in [`PROGRESS.md`](../../../PROGRESS.md) and the relevant domain page; the scenario page is reusable learning content, not a learner score.
